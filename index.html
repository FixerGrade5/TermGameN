วิธีการเติมเกม

  1. 1

    เลือกเกม

    เลือกเกมที่ต้องการเติมจากรายการเกมที่รองรับ

  2. 2

    เลือก Package

    เลือกแพ็กเกจและเซิร์ฟเวอร์ที่ตรงกับบัญชีของคุณ

  3. 3

    กรอก UID / Player ID

    กรอกข้อมูลที่จำเป็นสำหรับเติมเกม ไม่ต้องใช้รหัสผ่านใดๆ

  4. 4

    ตรวจสอบข้อมูล

    ตรวจสอบเกม เซิร์ฟเวอร์ แพ็กเกจ และราคาให้ถูกต้องก่อนส่ง

  5. 5

    ส่ง Order

    กดยืนยันคำสั่งซื้อ ระบบจะออกเลข Order ID ให้ทันที

  6. 6

    รอรับบริการ

    แอดมินดำเนินการเติมเกมให้ตามคิว พร้อมแจ้งผลผ่านช่องทางที่คุณให้ไว้

เราไม่ขอ Password หรือ OTP ของบัญชีเกม

ทุกคำสั่งซื้อใช้เพียง UID / Player ID / เซิร์ฟเวอร์เท่าที่จำเป็นเท่านั้น เราจะไม่มีวันสอบถามรหัสผ่านเกม, รหัสผ่าน Google/Apple, รหัส OTP หรือข้อมูลลับของบัญชีคุณไม่ว่ากรณีใดก็ตาม

คำถามที่พบบ่อย

FAQ

เติมเกมใช้เวลานานแค่ไหน

โดยทั่วไปคำสั่งซื้อจะดำเนินการภายในเวลาทำการของร้าน ระยะเวลาที่แน่นอนอาจแตกต่างกันไปตามคิวและช่วงเวลาที่สั่งซื้อ

ต้องให้ Password บัญชีเกมหรือไม่

ไม่ต้อง เราใช้เพียง UID / Player ID และเซิร์ฟเวอร์เท่านั้น ห้ามกรอก Password หรือ OTP ในแบบฟอร์มโดยเด็ดขาด

ถ้าราคาแพ็กเกจแสดงว่า "ติดต่อแอดมิน" ต้องทำอย่างไร

แพ็กเกจบางรายการยังไม่มีราคาระบุไว้ในระบบ กดปุ่ม "สอบถามราคา" เพื่อติดต่อแอดมินโดยตรงก่อนทำการสั่งซื้อ

เติมเกมเซิร์ฟเวอร์ต่างประเทศได้หรือไม่

ได้ ระบบรองรับหลายเซิร์ฟเวอร์ต่อเกม กรุณาเลือกเซิร์ฟเวอร์ให้ตรงกับบัญชีของคุณในหน้าเลือกแพ็กเกจ

ตรวจสอบสถานะ Order ได้อย่างไร

เก็บเลข Order ID ที่ได้รับหลังส่งคำสั่งซื้อไว้ แล้วแจ้งเลขนี้กับแอดมินเพื่อตรวจสอบสถานะ

สั่งซื้อผิดพลาดสามารถแก้ไขได้หรือไม่

กรุณาตรวจสอบข้อมูลให้ครบถ้วนก่อนกดส่ง Order หากพบข้อผิดพลาดหลังส่งแล้ว ให้ติดต่อแอดมินพร้อมแจ้ง Order ID โดยเร็วที่สุด

ชำระเงินอย่างไร

หลังส่ง Order แอดมินจะแจ้งช่องทางการชำระเงินให้ผ่านช่องทางติดต่อที่คุณระบุไว้ในแบบฟอร์ม

รองรับมือถือหรือไม่

รองรับ เว็บไซต์ออกแบบมาให้ใช้งานได้ดีทั้งบนมือถือและคอมพิวเตอร์
